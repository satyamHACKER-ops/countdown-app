# Countdown Clock

This is a ready-to-publish web app/PWA made from your Countdown Clock code.

Files:
- index.html — the app
- manifest.json — makes it installable as a PWA
- service-worker.js — basic offline caching

Easiest next step:
1. Create a free GitHub account at github.com if you don't already have one.
2. Create a new repository named `countdown-app`.
3. Upload all 3 files.
4. In the repository, open Settings → Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Choose the `main` branch and `/ (root)`, then Save.
7. GitHub will give you a public website address.
8. Open that address on Android Chrome and choose "Add to Home screen" / "Install app".

Note: the current design loads Tailwind CSS and Google Fonts from the internet, so the app's full styling still benefits from an internet connection.
